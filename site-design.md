1. This site is an open repository for AI-agents that can be used to generate isomorphic problem banks for physics.
2. The agents/skills are not installed in this project, rather, they are being packaged as downloadable zip files or installation files that others can download from the repo homepage.
3. Each agent generates a specific type of physics problem, such as conceptual multiple choice etc. 
4. File for each agent is contained in one folder with a Readme file. 
5. Each agent can have multiple forms: A skill for one specific platform (for example, cursor, codex, chatGPT, etc.), or a GUI that allow people to input their own API. Not all forms need to be present. All the different forms stay in one folder.
6. Help me design a central versioning convention for all the agents.
7. Each form of each skill should have a unified readme file that contains the author information and version information etc.
8. Each agent folder can also contains sample problem bank files that the agent has generated. PHYI problem bank is kept for now as example of problem bank formats.
9. The site homepage should list all the problem creation agents available, with a brief description of each agent, and information about the main author/authors. It would provide a button that points to a detailed agent page that shows more in the README page, displays download links for different forms of the agent, and displays the sample problem bank if available. (The sample problem bank display function can be added in later versions or included in README files.)
